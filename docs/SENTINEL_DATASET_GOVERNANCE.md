## 1. Principles of Dataset Integrity & Zero-Fabrication

Training artificial intelligence for state police operations demands absolute data integrity, legal provenance, and zero synthetic contamination in production validation sets.

### Core Governance Invariants:
1. **Strict Dataset Segregation:** Datasets must never be silently mixed or cross-contaminated. Every image, video clip, and annotation must carry an immutable data provenance category.
2. **Leakage Prevention:** Split assignments (Train / Validation / Test) must be made at the **Session / Video Source / Time Block** level, NEVER randomly by frame. Random frame splitting causes massive data leakage due to temporal correlation between adjacent video frames.
3. **BSA 2023 Section 63 Cryptographic Provenance:** Every training dataset release is sealed with a SHA-256 manifest hash and registered in the immutable lineage ledger.

## 2. Dataset Classification Taxonomy

Every data asset in Sentinel Grid must be categorized into exactly one of the following five tiers:

| Tier Code | Classification Name | Description | Allowed Usages | Retention Policy |
|---|---|---|---|---|
| `TIER-1` | `REAL_AUTHORIZED_DATA` | Real CCTV footage from Gujarat Police surveillance cameras authorized by SCRB/SP. | Production Training, Production Evaluation, Benchmarking. | 90 Days standard / Permanent for court evidence cases. |
| `TIER-2` | `TEST_HACKATHON_DATA` | Staged/controlled field test video collected with test vehicles and volunteer officers. | Algorithm Prototyping, Integration Testing, Acceptance Runs. | 365 Days. |
| `TIER-3` | `SYNTHETIC_DATA` | Digitally rendered plates, simulated weather artifacts (fog/rain/glare), or 3D engine vehicle renders. | Data Augmentation for rare classes (e.g. obscured laser PINs). **NEVER in Test Set.** | Ephemeral / Re-generable. |
| `TIER-4` | `DEMO_DATA` | Publicly licensed sample videos (e.g. YouTube CC, Pexels traffic) used for UI previews. | Offline UI demonstration, Sandbox mock testing. **NEVER in Training Set.** | Unrestricted. |
| `TIER-5` | `MODEL_GENERATED_DATA` | Pseudo-labeled frames generated by teacher models (Gemini Flash / Cloud Vision API). | Semi-supervised candidate mining. **Requires 100% human verification before promotion.** | Purged upon verification. |

## 4. Annotation Protocols & Quality Assurance

1. **Bounding Box Precision:** Bounding boxes must tightly enclose the visual boundary with a tolerance of $\le 3$ pixels.
2. **HSRP Security Mark Tagging:** Number plate annotations must specify attribute flags (`isHSRP: boolean`, `laserPinVisible: boolean`, `hologramVisible: boolean`, `indStripeVisible: boolean`).
3. **Double-Blind Review:** 15% of all annotated frames are subjected to random secondary review by a senior forensic examiner. Any batch with $>2\%$ annotation error rate is rejected for re-annotation.
4. **Export Formats Supported:**
   - YOLO TXT (`class_id x_center y_center width height`)
   - COCO JSON (Standard Object Detection Format)
   - Pascal VOC XML
   - Vertex AI AutoML CSV / JSON Lines
